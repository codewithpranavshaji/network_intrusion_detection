# Network Intrusion Detection Using Machine Learning

[![Python](https://img.shields.io/badge/Python-3.10+-blue)](https://python.org)
[![scikit-learn](https://img.shields.io/badge/scikit--learn-1.4+-orange)](https://scikit-learn.org)
[![Dataset](https://img.shields.io/badge/Dataset-UNSW--NB15-green)](https://research.unsw.edu.au/projects/unsw-nb15-dataset)

A complete, beginner-friendly machine learning project for academic submission.  
This system classifies network traffic records as **Normal** or **Attack** using
the UNSW-NB15 benchmark dataset and a Random Forest classifier.

---

## Project Overview

| Property | Value |
|---|---|
| Domain | Cybersecurity / Network Security |
| ML Type | Supervised Learning — Binary Classification |
| Algorithm | Random Forest Classifier |
| Dataset | UNSW-NB15 (University of New South Wales) |
| Labels | 0 = Normal traffic, 1 = Attack traffic |

**This is an offline ML project.** It classifies records from a static labeled
dataset. It does NOT perform live packet capture or network scanning.

---

## Main Features

- ✅ Complete training pipeline (load → preprocess → train → evaluate → save)
- ✅ Leakage-free preprocessing (fit only on training data)
- ✅ 5 diagnostic plots (class distribution, confusion matrix, ROC, F1, importance)
- ✅ Saved model artifact (reloadable for prediction on new data)
- ✅ 26 automated unit tests using synthetic data
- ✅ Optional Streamlit web interface for CSV upload + prediction
- ✅ Full academic report in `reports/report.md`

## Dataset Download

> ⚠️ The dataset files are **NOT included** in this repository (too large for Git).
> You must download them manually.

1. Visit: **https://research.unsw.edu.au/projects/unsw-nb15-dataset**
2. Download:
   - `UNSW_NB15_training-set.csv`
   - `UNSW_NB15_testing-set.csv`
3. Place both files in the `data/` folder:

```
NetworkIntrusionDetection/
└── data/
    ├── UNSW_NB15_training-set.csv
    └── UNSW_NB15_testing-set.csv
```

4. Verify:

```powershell
dir data\
```

## Installation

### Step 1 — Verify Python version

```powershell
python --version
# Should be Python 3.10 or newer
```

### Step 2 — Create a virtual environment (recommended)

```powershell
# Create the virtual environment
python -m venv .venv

# Activate it
.venv\Scripts\Activate.ps1
```

> **If activation fails** with a policy error, run this first:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```

### Step 3 — Install dependencies

```powershell
pip install -r requirements.txt
```

This installs: scikit-learn, pandas, numpy, matplotlib, seaborn, joblib,
streamlit, pytest.

---

## Running the Training Pipeline

**Requires:** Both dataset CSV files in `data/` (see Dataset Download above).

```powershell
python train_model.py
```

What this does:
1. Loads `data/UNSW_NB15_training-set.csv` and `data/UNSW_NB15_testing-set.csv`.
2. Validates schema and binary labels.
3. Builds the preprocessing pipeline and trains the Random Forest.
4. Evaluates on the test set and prints metrics.
5. Saves all outputs to `outputs/`.

Expected runtime: **2 – 10 minutes** depending on your CPU.

## Launching the Streamlit Interface (Optional)

The training pipeline must have run first (model must exist in `outputs/`).

```powershell
streamlit run app.py
```

Then open your browser at `http://localhost:8501`.

**How to use:**
1. Upload `data/UNSW_NB15_testing-set.csv` (or any compatible CSV).
2. The app automatically strips `label`, `id`, and `attack_cat` columns.
3. View predictions with colour-coded results and attack probabilities.
4. Download the full prediction CSV.

## Common Errors and Troubleshooting

| Error | Cause | Fix |
|---|---|---|
| `FileNotFoundError: UNSW_NB15_training-set.csv` | Dataset not downloaded | Download CSVs and place in `data/` |
| `ModuleNotFoundError: No module named 'sklearn'` | Dependencies not installed | Run `pip install -r requirements.txt` |
| `Model artifact not found` (in app.py) | Training hasn't run | Run `python train_model.py` first |
| `Set-ExecutionPolicy` error | PowerShell policy blocks .venv activation | Run `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| Memory error during training | Too little RAM | Close other apps; try n_estimators=50 as a temporary workaround |
| Streamlit script error on `use_column_width` | Very old Streamlit | Run `pip install --upgrade streamlit` |

## Known Limitations

- **Offline only.** This is not a live intrusion detection system.
- **Lab dataset.** UNSW-NB15 traffic is generated in a controlled environment.
  Real-world performance may differ.
- **No hyperparameter tuning.** The baseline RF configuration is reasonable
  but not necessarily optimal.
- **Attack probability ≠ proof of attack.** Model scores are statistical
  estimates that should be reviewed by a security analyst.
